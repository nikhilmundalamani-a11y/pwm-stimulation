PWM Simulator
v1.0 — EE Mini Project

⚙ Signal Parameters

Range: 0.1 – 100 000 Hz
50 % duty cycle selected
Typical: 3.3 V (logic) / 5 V (Arduino)

🔭 Future Scope

  • Arduino Integration — Export duty cycle / frequency values directly to an Arduino sketch via Serial or USB CDC.
  • Real-Time Hardware PWM — Stream live slider updates to an Arduino Uno/Mega using PySerial, controlling an actual LED or motor in real time.
  • Oscilloscope View — Capture real waveform data from a hardware ADC and overlay it on the simulated waveform.
  • Multi-Channel PWM — Simulate up to 6 independent PWM channels (mirrors Arduino Timer0/1/2).
  • PWM-to-DAC Emulation — Visualise the RC low-pass filter output beside the raw PWM signal.
