🔭 Future Scope

  • Arduino Integration — Export values directly to an Arduino sketch via Serial / USB CDC.
  • Real-Time Hardware PWM — Stream slider updates to Arduino via PySerial to control a real LED or motor.
  • Oscilloscope View — Capture ADC data from hardware and overlay on the simulated waveform.
  • Multi-Channel PWM — Simulate up to 6 independent channels (mirrors Arduino Timer0/1/2).
  • PWM-to-DAC Emulation — Show RC low-pass filter output beside the raw PWM signal.
